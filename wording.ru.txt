# ZARYA - FORM WORDING (Russian)
# Fill in the right-hand side of each "key =" line.
#
# HOW TO FILL
#   - Write only after the "=". Do not change a key and do not reorder lines.
#   - One line per entry. A line break inside a value is not supported.
#   - "Limit" is the character count that fits at that size in PT Sans, measured
#     against a Russian sample. NOTHING WRAPS: a longer string runs off the page.
#   - Lines starting with # are comments and are ignored.
#   - Leave a value empty to keep the English placeholder for now.
#
# HOW TO CHECK YOUR WORK
#   npm run wording:check    validates and reports, writes nothing
#   npm run wording:apply    applies it to the application
#
# The checker refuses a duplicate key, an unknown key, or a value too wide for
# where it is drawn. A missing key is reported but allowed.
#
# DO NOT TRANSLATE the stored option values (FOR, AGAINST, CATEGORICAL,
# NUMERICAL) or any zarya.* field name. Only printed text is Russian.
#
# EVERY FORM IS ONE A4 PAGE, top to bottom:
#   header    application name, form title, one grey line of service data
#   context   shaded read-only fields the application filled in
#   member    empty fields to fill in - the ONLY ones read back from the file
#   receipt   shaded read-only fields, empty until the transaction confirms

#
#  PART TWO - THE MATRIX REFERENCE REPORT
#
#  A SECOND, DIFFERENT DOCUMENT. Not a form: it has no fields and nobody
#  writes on it. It is the printed sheet a member reads BEFORE filling in a
#  voting form, to find out which coordinates (x, y) exist and what is in
#  them - because the contract cannot be asked what the matrix contains.
#
#  LANDSCAPE A4, one or more pages, top to bottom:
#    header    application name, document title, one grey line: block number
#              and chain time. Repeated on EVERY page.
#    notices   four grey lines of prose: what to do with the sheet, why it
#              expires, that a later refusal is expected, that it is not a
#              record
#    axes      "axis inventory" - the themes (by column) and statements (by
#              row) that exist. This is what a member needs in order to
#              propose a value where there is no cell yet
#    cells     "populated cells" - a table, grouped by column. The theme is a
#              heading over its column's rows; each row is one (x, y)
#
#  Because the page is landscape, the SENTENCES here have far more room than
#  the ones on a form - 193 characters instead of 133.
#
# ##########################################################################
# ##########################################################################
